## 9. Scoring System

| Answer result | Points |
|---|---:|
| Correct without hint | 10 |
| Correct with hint | 5 |
| Incorrect | 0 |

Normalized score:

    Score = earned points / maximum points * 100

Accuracy:

    Accuracy = correct answers / question count * 100

For example, four questions with two ordinary
correct answers, one hinted correct answer,
and one incorrect answer produce:

- Earned points: 25 / 40
- Normalized score: 62.5
- Accuracy: 75.0 percent

> $code = @'
import re

from pathlib import Path
from urllib.parse import unquote

root = Path.cwd()

documents = [
    root / "README.md",
    root / "docs" / "EVALUATION_EVIDENCE.md",
    root / "docs" / "COLLABORATION.md",
]

count = 0
missing = []

for document in documents:

    text = document.read_text(encoding="utf-8")

    for line in text.splitlines():

        if line.startswith("    "):
            continue

        links = re.findall(
            r"\[[^\]]*\]\(([^)]+)\)",
            line,
        )

        for link in links:

            if link.startswith((
                "http://",
                "https://",
                "#",
                "mailto:",
            )):
                continue

            target = unquote(
                link.split("#", 1)[0]
            )

            if not target:
                continue

            path = document.parent / target

            count += 1
